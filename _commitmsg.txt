feat(email): support Gmail SMTP (and email-to-SMS) — drop Postmark/Twilio requirement

The previous setup forced users into Postmark (needs a verified sender/DNS) and
Twilio (paid + verification). For an MVP that's overkill. Now we pick the first
configured transport in this order:

  1. Gmail SMTP — GMAIL_USER + GMAIL_APP_PASSWORD (free, no DNS).
  2. Generic SMTP — SMTP_HOST/PORT/USER/PASS for any other provider.
  3. Postmark HTTP API — POSTMARK_SERVER_TOKEN (kept as a fallback).

Also added MERCHANT_SMS_GATEWAY_EMAIL: optionally send the new-order alert to a
carrier email-to-SMS gateway (e.g. 6142904260@vtext.com) so the merchant's
phone buzzes with a text — no Twilio account required.
