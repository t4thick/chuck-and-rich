Admin: full UX redesign + design-system alignment

The admin section was fully functional but visually raw — bare HTML
tables and unstyled inputs that didn't match the storefront polish.
This brings every admin surface up to AGENTS.md standards while
keeping things utility-first and snappy.

Pages
- /admin (Dashboard): KPI cards for Today / 7d / 30d / MTD with deltas;
  ops cards (Products / OOS / Orders / Open / Customers / Prior month);
  recent orders shown in modern striped table with colored status pills.
- /admin/products: image thumbnail + name + category + price + stock,
  desktop table on >= sm, mobile card list on smaller screens.
- /admin/orders: status filter pills with counts, leading search input
  with icon, color-coded status pills per row, mobile card list.
- /admin/orders/[id]: 2-column layout (customer + items + address on
  left, timeline + status updater + refund on right), icon timeline
  with checked steps, audit log table full-width below.
- /admin/customers: role pill, total spent, desktop table + mobile cards.
- /admin/products/new + edit: constrained max-w-3xl page, back link,
  consistent header.

Components
- AdminSidebar: sticky glass header, icon + label per tab, active state
  pill (bg-earth-900), logout & "View store" buttons.
- AdminOrderNotifier: real toasts (fixed bottom-right, animate-pop,
  green ShoppingBag icon, dismiss button); permission/sound controls
  moved to a thin status strip under the header.
- ProductForm: design-system Input/select/textarea, drag-style image
  upload card with thumbnail preview + remove, character-aware notes.
- OrderStatusUpdater: 2-col grid, design-system inputs, 500-char
  counter on notes, animated Check badge on save.
- RefundButton: design-system inputs, destructive button variant,
  animated success state.
- DeleteProductButton: styled as a subtle text-red link, not a raw
  browser button.

Tokens / globals
- Added .admin-card, .admin-page-title, .admin-section-title,
  .admin-kpi/.admin-kpi-label/.admin-kpi-value/.admin-kpi-delta,
  .admin-table-wrap, .admin-table, .admin-status-pill utility classes.
- Button: transition-all 300ms -> transition-colors 150ms (AGENTS.md
  caps motion at 200ms).

No functional changes — same auth (8h HMAC cookie + rate limit), same
APIs, same Supabase queries.
